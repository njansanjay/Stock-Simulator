# 📈 Stock Simulator Pro
![Status](https://img.shields.io/badge/status-active-success?style=for-the-badge)

Stock Simulator Pro is a modern virtual stock market simulator built using pure HTML, CSS, and JavaScript.

It simulates a real-time trading environment where users can buy and sell stocks, track portfolio performance, and visualize market trends through a clean fintech-style dashboard.

---

## ✨ Features

* 📈 Real-time simulated stock price updates
* 💰 Buy & Sell stocks
* 💼 Portfolio tracking
* 📊 Live market trend graph
* 🌙 Dark / Light mode
* 🔍 Stock search functionality
* 💾 LocalStorage data persistence
* 🎨 Modern minimal fintech UI

---

## 🧠 Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript

### Libraries

* Chart.js
